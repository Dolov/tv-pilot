RULES / 边界

  • 数据类别色不参与。视频粉 / 音乐青 / 儿童橙 / 系统灰在任何色系下色相不变，只允许微调明度。
  • 纯黑只对 OLED 推荐。LCD 上会显灰；近黑渐变更容易出色带，所以默认仍是暖石墨。
  • 语气与角标不开放。孩子区固定 story，屏保角标固定白字 + 投影，不跟主题。
  • 新增色系只加数据。4 个 token 组 + 1 条对比度断言即可，不改组件、不改布局。
  • 不提供任意取色。16 个组合是策展边界，保证 3 米可读与类别可辨。
