# 使用报告（周报 / 月报 / 年报）设计

状态：**已实现（v1.13）**。方向：企业级可视化数据大屏，**三档三套信息架构**。
视觉稿源码与截图在 `.build/design/`（本地生成，不入库）。实现时按文末「分期」拆 PR。

## 0. 核心判断

实现落点：`ReportsActivity` + `WeekReportView` / `MonthReportView` / `YearReportView`，共用
`ReportCanvasView` 的卡片、KPI、周期条与基础图表；数据侧为 `ReportEngine` / `ReportMath` / `DayAgg` / `Report`，
纯计算几何（纵轴 `ChartAxis`、堆叠柱 `BarStack`）单独成类并进单测。
与本文的差异：周期条窗口跟随「当前查看」而不是固定结束在今天（因此回看旧周期时，
「本期圆点」可能不在条内）；空数据时洞察会降级为「本期没有记录到使用时间」，KPI 峰值显示「—」；
月报周内平均与洞察都只统计有记录的日子；年报表里没有记录用量的月份不参与同比；
最早一期被 365 天窗口截断时按真实覆盖区间计算。

值得做，成本可控：数据已经在盘上（`HistoryStore` 按天存档 365 天，含分段和播放记录），
今天的还在 `HudService` 内存里。**不新增采集、不加权限、不动 1s 采样**，
只是「读已有数据 → 聚合 → 渲染」。

关键修正（第一版设计的问题）：**周 / 月 / 年不能是同一个模板换 x 轴**。三档回答的是不同问题：

| 粒度 | 回答的问题 | 专属图表 |
|---|---|---|
| 周报 | 这周每天怎么过的？和上周比呢？ | 7 天节奏大柱 + 日流水 + 7×24 作息热力 |
| 月报 | 哪几天、哪一周看得多？周内规律是什么？ | 日历热力 + 每日趋势 + 周内平均 |
| 年报 | 全年走势、季节性和结构变化？ | 12 个月走势 + 月份×时段热力 + 季度构成 |

共用的只有：顶部导航、4 张 KPI 卡（指标按粒度不同）、一句话洞察、周期导航条、页脚。

## 1. 目标 / 非目标

目标：

1. 一眼回答：这期看了多久、比上期多还是少、什么时候看、看什么；
2. 周 / 月 / 年三档可切换，且能回看上一期、上上期（到 365 天窗口边界）；
3. 图表「有信息量的酷」：渐变、发光、卡片化，但不做无意义装饰；
4. 低端电视 ≤1s 打开，遥控器只用一个方向键 + 返回。

非目标：实时大屏；逐日下钻（P2）；3D / 粒子 / 无限动画；云端同步；导出分享（P2）。

## 2. 口径

| 项 | 口径 |
|---|---|
| 周期 | 周 = 周一起 7 天；月 = 自然月；年 = 自然年；本地时区 |
| 本期未结束 | 统计到「今天 0 点 + 今日实时」；标「进行中」，未来日期不画数据、只留基线 |
| 日均 | 总时长 ÷ 已过天数（含无记录日）；有记录天数单独展示 |
| 覆盖区间 | 最早那一期可能被 365 天保留窗口截断，此时「已过天数」只算窗口内的天；页头区间显示真实起点 |
| 覆盖率 | 有存档天数 / 已过天数；页脚常驻，缺数据不补零 |
| 环比 | 日均 vs 上一同粒度周期；上期覆盖 < 80% 或超出保留窗口时显示「无同比」 |
| 单日峰值 | **始终取日粒度**（最大单日），不能用月柱最大值冒充 |
| 年报洞察 | 月与月比**日均**，不比总时长（2 月天然少 2–3 天） |
| Top 片单 | 按集数排序，右侧最近观看时间；不把 `PlayEntry.durMs` 当观看时长 |
| 颜色 | 分类色沿用 `Categories`；青色只做界面强调与均值线 |

## 3. 信息架构

```
HomeActivity
├── 使用记录        → MainActivity（今日台账 + ←→ 历史回看）
├── 使用报告  ← 新增 → ReportsActivity（本设计）
├── 我的宠物        → PetActivity
└── 家长设置        → PetSettingsActivity（PIN）
```

`ReportsActivity` 一个 Activity，三种布局。**不是 tab 切换同一套 View**，而是按粒度走三套渲染函数
（可以理解为三个子页），共用卡片/图表基础组件。

## 4. 三套一屏布局（1920×1080 → 960×540dp）

公共框架：顶部 36dp 标题区 + 24dp 洞察行；4 张 KPI 卡（62dp 高）；内容区两行（170dp + 155dp）；
周期导航条 48dp；页脚 8dp；左右安全边距 48dp。

### 4.1 周报：「这一周怎么过的」

```
tv-pilot │ 使用报告   2026.10.26–11.01 已归档      [周报 月报 年报] ‹第 44 周› 回到本期
洞察  周六最长（4:04），周二最短（1:54）；19–21 点最集中。
┌ 合计 20h44m ┬ 日均 2h58m ┬ 单日峰值 4h04m ┬ 周末日均 3h51m（工作日 2h36m）┐
├──────────────────────────────┬──────────────────────────────────────────┤
│ 7 天节奏 DAILY RHYTHM         │ 日流水 DAY BY DAY                        │
│ [100% 分类构成条 + 图例]       │ 周一 10/26 16:56–21:06 2:27 视频 星球小队 │
│ 7 根大柱（周一…周日）          │ … 7 行，每天从几点看到几点               │
│ 柱顶总时长 / 上期虚线刻度      │                                          │
├──────────────────────────────┤ 看了什么 TOP CONTENT                     │
│ 时段分布 7×24（这一周的作息）  │ 排行：集数 + 最近观看                     │
└──────────────────────────────┴──────────────────────────────────────────┘
周期导航条：近 8 周，选中「10/26」，本周 11/02 带圆点
```

- KPI 第 4 张换成「周末日均」，直接回答「周末和工作日差多少」；
- 7 根柱子画得大，柱顶写总时长，虚线刻度 = 上一周同星期（图例标出对比周序号），一眼看出哪天回落；
- 「日流水」是周报独有的表格感模块：7 行，每行 = 周几 / 日期 / 起止时间 / 时长 / 主类别 / 片名。

### 4.2 月报：「这个月的规律」

```
tv-pilot │ 使用报告   2026.10.01–10.31 已归档      [周报 月报 年报] ‹10 月› 回到本期
洞察  周末日均比工作日多 90 分钟；19 点前后最集中。
┌ 合计 94h57m ┬ 日均 3h04m ┬ 单日峰值 4h44m ┬ 有记录 31/31 天 ┐
├──────────────────────────────────────┬─────────────────────────────────┤
│ 日历热力 CALENDAR                     │ 内容构成 MIX（环形图 + 图例）    │
│ 7 列日历，每格 = 日号 + 时长，亮度=时长 │ 中心：本期总时长                 │
├──────────────────────────────┬───────┴──────────────┬──────────────────────┤
│ 每日趋势 DAILY TREND          │ 周内平均 BY WEEKDAY   │ 看了什么 TOP CONTENT │
│ 31 根柱 + 周末底色 + 日均虚线 │ 7 根柱：周一…周日     │ 排行                  │
└──────────────────────────────┴──────────────────────┴──────────────────────┘
```

- 月报的招牌是**日历热力**：直接看到「哪几天密集、哪一周空白、周末是否更长」；
- 周内平均回答「这个月是不是固定周末看」，比再放一张 7×24 小时热力更有信息量；
- 环形图保留，结构占比在月粒度最稳定。

### 4.3 年报：「全年走势与结构」

```
tv-pilot │ 使用报告   2026.01.01–11.06 进行中      [周报 月报 年报] ‹2026 年›
洞察  10 月日均最高（3:04），2 月最低（2:48）；19 点前后最集中。
┌ 合计 892h46m ┬ 日均 2h53m ┬ 最高月 94h57m（10 月·月均81:10） ┬ 覆盖 310/310 天 ┐
├────────────────────────────────────────────────────────────────────────────┤
│ 全年走势 12 MONTHS：12 根月柱 + Q1–Q4 分隔 + 月均虚线 + 峰值气泡            │
├──────────────────────────────┬────────────────────┬────────────────────────┤
│ 月份 × 时段 SEASON × HOUR     │ 季度构成 QUARTERS   │ 看了什么 TOP CONTENT    │
│ 12×24 热力（季节性 × 时段）    │ Q1–Q4 分类堆叠条     │ 年度榜                  │
└──────────────────────────────┴────────────────────┴────────────────────────┘
```

- 年报不再用 7×24（那是「周几×几点」的重复），换成 **12 个月 × 24 小时**：能看出「暑假晚上看得多」这种季节性；
- 季度构成用 4 条水平堆叠条，比一个全年环形更能看出结构在一年里的漂移；
- 最高月用「月均」做 KPI 3，避免和「月总时长」混淆。

## 5. 交互（遥控器）

| 键 | 行为 |
|---|---|
| `←` / `→` | 上一期 / 下一期（按当前粒度），不能翻到未来，最早到 365 天窗口 |
| `↑` / `↓` | 粒度缩放：周 → 月 → 年（↑ 变粗，↓ 变细），边界停住 |
| `OK` | 不在本期时「回到本期」；已在本期时无操作（P2 再做下钻） |
| `返回` | 回首页 |

- 顶部步进器显示具体周期名（第 45 周 / 11 月 / 2025 年；不在当年时补归属年份，如 2024 年 11 月），范围用绝对日期；
- 底部周期导航条：近 8 周 / 近 7 个月 / 近 3 年；选中项描边，真正「本期」带圆点；
- 粒度切换保留锚点：在上周按 ↑ 进月报 → 落到该周所在月份；翻页后锚点 = 区间首日；
  锚点第一期已出 365 天窗口时（如从去年的年报按 ↓）落到窗口内最早一期，不跳回本期；
- 聚合异步 + token：连按只渲染最后一次；后台任务开始前比对 token，过期请求跳过（不排队跑完）；
  长按方向键只认第一下（忽略 repeatCount）；加载中保留上一帧画面，失败显示「按 OK 重试」；
- 报告页在前台时 `HudService.isOwn()` 已排除自己，数字稳定，无需 60s ticker；
- 记住上次粒度（`SharedPreferences("hud")` 的 `report_period`）。

| 项 | 值 |

| 背景 | `#06090f` + 青/粉径向光晕 + 64px 工程网格（径向遮罩淡出） |
| 卡片 | `#131e2b → #090f17` 渐变，1px `rgba(120,170,220,.14)`，12dp 圆角，顶部青色高光条，右下切角 |

| 分类色 | `#f43098` 视频 / `#00d3bb` 音乐 / `#ffb74d` 儿童 / `#90a4ae` 系统 / `#607d8b` 其他 |
| 文本 | `#e8f0f8` / `#93a4b8` / `#5c6b7d`；数字 DIN Pro，中文系统兰亭 |
| 字号 | KPI 数字 23dp、卡片标题 11dp、正文/图例 9–10dp、轴标签 8–9dp、页脚 8dp |
| 发光 | 只给线、环形、热力高亮、当前标记；不整卡泛光 |
| 装饰 | 网格 / 切角 / 顶部高光 / 极细刻度；不做粒子、3D、无限呼吸动画 |

实现注意：

- 派生数据（KPI、月汇总、月×时热力、7×24 热力）在 `setReport` 时预计算一次，`onDraw` 只画；
  背景径向光晕的 Shader 与字体在构造时建一次（当前网格只有 47 条线，直接画即可）；
- 发光不要用 `BlurMaskFilter`（硬件加速下开销大且不一致），用「宽 4px 20% 透明底线 + 正常线」叠；
  热力格的高亮可以用低透明度 `shadowLayer` 或预烘的小 Bitmap；
- 入场动画只做一次 300ms（柱高生长 / 环形 sweep），翻页和刷新不做。

## 7. 数据层与聚合

### 7.1 新增类

| 文件 | 职责 |
|---|---|
| `ReportPeriod.java` | 粒度枚举 + 周期边界 / 平移 / 具体标签（第 N 周、M 月、YYYY 年） |
| `DayAgg.java` | 单日：`totalMs`、`catMs[5]`、`hourMs[24]`、起止时间、主类别 |
| `Report.java` | 一次渲染的序列：KPI、日柱、上期、日历、周内均值、月柱、月×时热力、季度、Top、周期条 |
| `ReportMath.java` | 纯函数：分段→日汇总/小时桶、周期聚合、环比、峰值、最大余数 |
| `ReportEngine.java` | 读历史 + 今天，异步、缓存、token |
| `ReportsActivity.java` | 三套布局的组装与按键 |
| 图表 View 见 §6 | 自绘组件 |

改动：`HomeActivity`（菜单项）、`AndroidManifest.xml`（注册 Activity）、
`HistoryStore`（`v` 字段）、`version.properties` + Manifest（1.13 / 14）。
**不动**：`HudService` 采样、`UsageDay` 当天模型、`MainActivity` 台账。

### 7.2 一次扫描，三套视图复用

```text
windowStart = min(周期条起点, 上期起点, 本期起点)   // 月报约 7 个月，年报 365 天
for day in [windowStart, today]:
    dayAgg = 历史文件 + 今天内存
    perDay[day] = dayAgg
然后派生：
  周报 = 7 个 dayAgg + 每天起止 + 主类别 + 上期同星期
  月报 = 31 个 dayAgg + 日历矩阵 + 每周几均值 + 环形
  年报 = 12 个月聚合 + month×hour 桶 + 4 个季度聚合
  周期条 = 按周期分组求和；上期 = 同窗口再组合
```

复杂度 O(天数 × 段数)；365 天 DayAgg 只存 5+24 个 int，内存可忽略。

### 7.3 性能

- 后台单线程 + 骨架屏；进程内缓存 `HashMap<period+anchor+dataVersion, Report>`；
- 目标年报首屏 ≤ 800ms；超标加日汇总缓存 `files/history/summary/yyyy-MM.json`；
- 三套布局切换不重新读盘，只重算当前粒度需要的派生序列。

### 7.4 数据版本（前置改动）

给归档 JSON 加 `"v": UsageDay.SCHEME`；读取时缺省按 3。
`v != SCHEME` 的天只计总时长，不进分类/热力/环形，并在覆盖度旁提示「N 天为旧分类口径」。

### 7.5 边界

| 情况 | 处理 |
|---|---|
| 完全没有历史 | 空态 + 今日实时 |
| 部分天缺失 | 正常展示 + 覆盖率；不补零 |
| 早于 365 天 | 允许选到窗口内的部分周期；起点钳到 `today-364`，日均/覆盖率只算窗口内天数并显示真实区间；窗口外的天不补零、不算「没看」 |
| `peekUsage()` 为 null | 回落 `UsageDay.load(prefs)` |
| 播放日志轮转 | Top 区降级；日流水「片名」留空 |
| 跨月/跨年周 | 周一只按周一起算；周序号按 ISO 8601（含 1/4 的周为第 1 周），跨年周补归属年份（如 2024 第 1 周） |
| 快速连按 | 忽略长按重复键；后台任务开头比对 token，过期请求直接跳过；渲染前再比对一次 |
| 年报无可比上一年 | KPI「无同比」，不画上期线 |

## 10. 风险

| 风险 | 应对 |
|---|---|
| 三套布局代码量翻倍 | 共用卡片/图表基础组件；三页各自只写布局与派生序列 |
| 大屏风格与现有台账反差大 | 仅报告页使用；需要全局统一时另做主题 |
| 信息密度过高 | 最小 8dp、正文 9dp；真机可读性差时优先砍日流水/周内平均 |
| 发光/渐变低端机掉帧 | 预计算派生数据；Shader/字体复用；发光叠线；动画只入场 |
| 365 文件聚合超时 | 单次扫描 + 缓存；>800ms 加日汇总 |
| 数据不完整导致误读 | 覆盖率常驻、缺数据不补零、无同比说清 |
